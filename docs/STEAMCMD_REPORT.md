# Фактическая проверка анонимной загрузки SteamCMD

Дата: 11 ноября 2026 года. Среда: Ubuntu 24.04, x86_64.
Steam Console Client: `1792617903`. Учётная запись: anonymous; пользовательские
учётные данные Steam не использовались. Проверка проведена с доступом к сети
вне DNS-песочницы. [Сохранённый вывод](evidence/steamcmd-anonymous-281990.txt).

## Результат

| Проверка | Результат |
|---|---|
| Загрузка официального SteamCMD и самообновление | PASS |
| `login anonymous` | PASS, подключение и информация пользователя получены |
| `app_update 281990 validate` | Код 0, сообщение об успешной установке, **файлов игры нет** |
| Проверка установленного содержимого | `SizeOnDisk = 0`, `BytesDownloaded = 0`, `InstalledDepots` пуст |
| `app_info_print 281990` | Публичные метаданные доступны, public buildid `26557690` |
| Загрузка основного депо `281991` | Код 14, `missing license for depot (No subscription)` |
| Оригинальные скрипты и движок Stellaris | NOT AVAILABLE |

Таким образом, в этой проверке получен настоящий отказ лицензирования.
Предыдущую несостоявшуюся проверку с ошибкой DNS нельзя ретроспективно считать
таким отказом. Сообщение `fully installed` при пустом списке депо также
нельзя считать загрузкой игры. Из этого результата не следует, что
авторизованная учётная запись с лицензией не сможет скачать игру.

## Воспроизведение

Официальный установщик:
<https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz>.
Использовать отдельный каталог установки, не существующую пользовательскую игру.

```sh
steamcmd +force_install_dir /tmp/telluric-stellaris \
  +login anonymous +app_update 281990 validate +quit
steamcmd +login anonymous +app_info_update 1 +app_info_print 281990 +quit
steamcmd +login anonymous \
  +download_depot 281990 281991 8284331313639661868 +quit
```

Manifest ID взят из `app_info_print` для public-ветки в момент проверки;
при повторении получить актуальный ID. Депо `281991` — основное содержимое,
его метаданные указывали размер 29 748 229 605 байт. Полная загрузка не состоялась.

Первый запуск не работал из-за отсутствия 32-битного загрузчика. Пакеты Ubuntu
`libc6-i386`, `lib32gcc-s1`, `lib32stdc++6` скачаны через `apt download` и
распакованы через `dpkg-deb -x` в `/tmp/telluric-steamcmd/runtime`, без
системной установки. Bootstrap запущен явным локальным `ld-linux.so.2`;
он распаковал обновление в `runtime/usr`. После самообновления использован
его исполняемый файл `runtime/usr/linux64/steamcmd`. Возврат bootstrap с
кодом 42 означал необходимость перезапуска; это не результат `app_update`.

## Исторический блокер и его снятие

После этой анонимной проверки пользователь самостоятельно загрузил лицензированную Linux-копию 4.5.4 (1b4f) в `/tmp/telluric-stellaris`. 11 ноября блокер данных снят: аудит и загрузочный smoke-test выполнены, см. [текущий отчёт](TEST_REPORT.md). Отказ anonymous по-прежнему является фактом именно анонимной проверки.

Для воспроизведения проверки по законно полученной установке:

```sh
STELLARIS_GAME_DIR=/path/to/Stellaris make check-game
```

Затем сверить фактический патч/checksum, классы, технологии, terraform links,
сюжетные ограничения и DLC по плану DESIGN.md и RUNTIME_CHECKLIST.md.
Ни публичные метаданные Steam, ни текущая offline-сборка этого не заменяют.
Файлы игры не добавлены в репозиторий или архив мода. Во время описанной здесь анонимной проверки движок не запускался; последующие запуски отражены в текущем TEST_REPORT.md.
