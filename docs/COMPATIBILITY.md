# Совместимость

Цель: Stellaris PC 4.5.4 (1b4f). Оригинальные Linux-данные 4.5.4 проверены; загрузка файлов мода реальным движком проверена. Игровые сценарии и Windows runtime пока NOT TESTED.

Standalone, обязательных модов и DLC не требует. Условия кандидатов Detox/knights_detox и Hydrocentric сопоставлены с оригиналами; World Shaper и специальные направления не изменены. Полная DLC-совместимость не заявляется без игровых сценариев. Новые пути Wilderness скрыты, оригинальные сохранены. Классы неизвестного происхождения не получают общих конверсий.

Size Matters не доступен для испытаний; настроечный диапазон размеров сейчас 10–40. Большие миры вне диапазона блокируются. Это условный ограничитель баланса.

Другие моды common/terraform могут дублировать или переопределять пары. Без установленных данных давать универсальный порядок загрузки нельзя. Специальные миры пока не получают новых исходящих переходов. Модель покрывает все 69 определённых классов установленной 4.5.4; изменение полного множества выявляет check-game. Совпадения from/to с кандидатами (28 пар) разделены potential; фактическое меню ещё необходимо проверить.

Старые сейвы НЕ проверены, включая Кибрекс-Альфу. Не загружать основной сейв с dev-сборкой. Резервная копия обязательна. Удаление мода не является откатом терраформирования; восстанавливать исходную резервную копию. Checksum и достижения/Ironman не тестировались; сохранение достижений не обещается.

Новые пути не затрагивают сами классы Ring World/Cybrex/Arkship и запрещены во всей системе с мегасооружением. Это также закрывает обычные соседние миры систем с Gateway/Hyper Relay; до точечных испытаний применяется консервативное ограничение. ИИ новых проектов отключён. Vanilla-климатические переходы и их требования для колоний сохранены.
