# Совместимость

Цель: Stellaris PC 4.5.4 (1b4f). Реально протестированных версий игры: нет.

Standalone, обязательных модов и DLC не требует. DLC-механики и преимущества Detox/Hydrocentric/World Shaper пока не прошли аудит, поэтому совместимость не заявляется. Классы неизвестного происхождения не получают общих конверсий.

Size Matters не доступен для испытаний; настроечный диапазон размеров сейчас 10–40. Большие миры вне диапазона блокируются. Это условный ограничитель баланса.

Другие моды common/terraform могут дублировать или переопределять пары. Без установленных данных давать универсальный порядок загрузки нельзя. Специальные миры пока не получают новых исходящих переходов. Перечень классов в модели — предварительная инвентаризация, не подтверждённый полный список 4.5.4.

Старые сейвы НЕ проверены, включая Кибрекс-Альфу. Не загружать основной сейв с dev-сборкой. Резервная копия обязательна. Удаление мода не является откатом терраформирования; восстанавливать исходную резервную копию. Checksum и достижения/Ironman не тестировались; сохранение достижений не обещается.
