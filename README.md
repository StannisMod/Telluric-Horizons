# Telluric Horizons — Planetary Engineering

Научно мотивированное терраформирование каменистых миров для Stellaris.

**Состояние: 0.1.0-dev, незавершённая разработка. Не устанавливать в основную партию.** Цель — 4.5.4 (1b4f), подтверждённая официальными новостями на 11 ноября 2026 года. Игровых данных и движка в среде разработки нет. Поддержка патча пока НЕ подтверждена испытаниями.

## Что реализовано

Единая JSON-модель, валидатор инвариантов, детерминированный генератор, 36 направлений из Barren / Cold Barren / Frozen / Toxic к девяти основным климатам, RU/EN подсказки, матрица переходов, упаковка и автономный CI. Игре не нужны Python или внешние библиотеки.

Это инженерная основа, а не завершение полного ТЗ. Ванильные климатические и DLC-переходы пока сохранены без изменения; переоценка их цен требует оригинальных данных. Защита уникальных миров, обработка месторождений, преимущества кандидатов/Detox и экономическое поведение ИИ ещё требуют реализации и проверки на оригинальных определениях. ИИ для новых переходов пока отключён намеренно.

## Разработка без игры

Требования: Python 3.11+ и GNU Make. Сторонних Python-зависимостей нет.

```sh
make lint
make test
make build
make check-generated
make package
```

Исходник: `model/terraforming.json`. Генератор: `tools/build.py`. Выход: `generated/`. Архив: `dist/telluric-horizons-0.1.0-dev.zip`. Сгенерированные файлы вручную не редактировать. После правки модели выполнить build, проверки и закоммитить generated вместе с исходником.

Проверка ссылок по законно полученной локальной копии игры (файлы используются только для чтения):

```sh
STELLARIS_GAME_DIR=/path/to/Stellaris make check-game
```

Без пути команда возвращает статус 2 (NOT TESTED). Эта проверка ищет определения классов и технологий; она не проверяет весь синтаксис и выполнение скриптов.

11 ноября фактически проверен анонимный SteamCMD: вход работает, но `app_update` создаёт пустую установку, а загрузка основного депо возвращает `No subscription`. Данные игры недоступны; [команды и доказательства](docs/STEAMCMD_REPORT.md).

## Пробная установка Linux / Windows

Только для отдельного тестового плейсета и новой партии. Сначала сохранить резервную копию пользовательских сейвов. Распаковать содержимое архива в пользовательский каталог Stellaris `mod`, чтобы рядом находились `telluric_horizons.mod` и папка `telluric_horizons`. Linux обычно использует `~/.local/share/Paradox Interactive/Stellaris/mod`, Windows — `Documents/Paradox Interactive/Stellaris/mod` (путь может быть перенаправлен OneDrive). Включить мод в отдельном плейсете лаунчера. Если он не обнаружен, проверить фактический каталог пользовательских данных.

Не применять к основному сейву до прохождения [игрового чеклиста](docs/RUNTIME_CHECKLIST.md).
